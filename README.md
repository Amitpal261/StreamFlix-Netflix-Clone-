A **high-performance Netflix-inspired web app** built with modern technologies like **React, Next.js, Firebase, and React Query**, now enhanced with **AI-powered features**.
A **high-performance Netflix-inspired web app** built with modern technologies like **React, Next.js, Firebase, and React Query**, now enhanced with **AI-powered features**.
